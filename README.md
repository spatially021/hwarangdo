# 화랑검
## 개요
게임 엔진과 프로그래밍 언어를 병합한 프로그램.  
c/c++의 문법을 기초로 하되 포인터, GC를 사용하는 것 대신 rust의 소유권 개념을 융합하여 빠른 속도와 메모리 관리를 하는 것이 목표.  
또한 게임 엔진을 언어 수준에서 묶어 언어와 라이브러리 사이에서 발생하는 간극을 줄이는 것 또한 목표.  
## 문법
기초 문법은 c/c++ 계열 언어와 유사하게 작성.
### 변수 선언
자료형 변수명;  
자료형 변수명 = 값;  
ex) int a; int b=10;
  
### 자료형
|자료형|크기|특징|
|------|---|---|
|int|64비트 정수형|-|
|float|32비트 실수형|-|
|double|64비트 실수형|-|
|char|8비트 문자|-|
|string|문자열|-|
|boolean|논리값|-|

### 조건문
if(조건){}  
switch{case 1:}

### 반복문
for(반복조건){}  
while(조건) {}  
  
break, continue도 마찬가지로 작동

### 함수
자료형 함수명(){} 과 func 함수명(){} 하이브리드로 작동
자료형에는 void가 포함되며 return이 없는 func은 void로 취급함. return이 있으면 해당 자료형으로 변환하여 연산함
